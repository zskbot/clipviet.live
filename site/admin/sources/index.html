API source configuration

Nguồn API được khai báo trong scripts/sync-pages-catalog.mjs của repository. Các endpoint trong báo cáo hiện là API anonymous; không có API key để nhập. Nếu nhà cung cấp cấp endpoint hoặc credential riêng, chỉ cấu hình trong GitHub Actions Secrets và cập nhật script để đọc secret ở server-side — tuyệt đối không đặt token trong JavaScript public.

Đồng bộ tự động mỗi 6 giờ; tối đa 3 trang/provider trong mỗi lần chạy. HLS/MP4 phát trực tiếp từ CDN nguồn trên trình duyệt.
