CLIPVIET.LIVE / INTEGRATION REGISTRY

Repository tích hợp

Sáu repository được rà soát để định hình các mô-đun của nền tảng video: danh mục nguồn live, tìm kiếm metadata, phân tích video và công cụ biên tập. Đây là danh mục tham chiếu; không có repository bên ngoài nào được tự động thực thi hoặc cấp quyền phát nội dung.

Đang tải danh mục repository…

Chỉ đưa video vào thư viện khi ClipViet có quyền phân phối hợp lệ, nguồn có điều khoản sử dụng rõ ràng và nội dung đã qua kiểm duyệt. Không tự động tải xuống, scrape, proxy hoặc phát playlist từ repository bên ngoài. Nội dung người lớn phải được tách biệt, có kiểm soát truy cập phù hợp và không được nhắm tới người chưa thành niên.

SYSTEM BOUNDARIES

Kiến trúc tích hợp

  • site/ là frontend tĩnh: chỉ hiển thị thư viện, registry và admin thử API trên trình duyệt.
  • Next.js và các server routes trong repository không thuộc target triển khai của GitHub Pages.
  • Provider adapter phải chuẩn hóa metadata, kiểm tra HTTPS, allowlist embed host, timeout và giới hạn dữ liệu.
  • Player phát URL media HTTPS từ catalog đã đồng bộ trực tiếp trên trình duyệt; không proxy stream.

ClipViet GitHub Pages sử dụng catalog JSON tĩnh được đồng bộ bởi GitHub Actions; trang quản lý nguồn chỉ đọc trạng thái đồng bộ.
