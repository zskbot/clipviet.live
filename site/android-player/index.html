ANDROID NATIVE PLAYER / INTEGRATION

JiaoZiVideoPlayer

Android playback companion for ClipViet · SDK 7.7.0 · MIT License

MỞ SOURCE CODE ↗ UPSTREAM ↗
Phân biệt nền tảng: JiaoZiVideoPlayer là thư viện giao diện/phát video native cho Android (View Android). Nó không phải JavaScript player và không thể nhúng trực tiếp vào website hoặc iPhone Safari. ClipViet Web tiếp tục dùng HTML5/HLS và API.video SDK; Android app có thể dùng JiaoZiVideoPlayer làm lớp native.

1. Thêm thư viện Android

repositories {
    google()
    mavenCentral()
}

dependencies {
    implementation 'cn.jzvd:jiaozivideoplayer:7.7.0'
}

Module upstream hiện khai báo minSdk 24, AndroidX và Java 8 bytecode. Kiểm tra compileSdk/AGP của app Android trước khi nâng cấp.

2. Khai báo player trong layout

<cn.jzvd.JzvdStd
    android:id="@+id/clipviet_player"
    android:layout_width="match_parent"
    android:layout_height="220dp" />

3. Nạp video đã được cấp quyền phát

JzvdStd player = findViewById(R.id.clipviet_player);

// playbackUrl phải do backend ClipViet cấp sau khi kiểm tra
// quyền phân phối, trạng thái video và thời hạn URL.
player.setUp(playbackUrl, videoTitle);

4. Vòng đời Activity

@Override
public void onBackPressed() {
    if (Jzvd.backPress()) return;
    super.onBackPressed();
}

@Override
protected void onPause() {
    super.onPause();
    Jzvd.releaseAllVideos();
}

5. Quy tắc tích hợp ClipViet

  • Chỉ yêu cầu URL phát từ backend sau khi bản ghi đã được duyệt quyền phát.
  • Ưu tiên HTTPS; không bật cleartext traffic toàn ứng dụng.
  • Không đưa API.video API key, private token hoặc thông tin xác thực vào APK/client.
  • Không dùng URL demo hoặc video mẫu làm nguồn mặc định.
  • Kiểm thử portrait/landscape, pause/resume, back press, mạng yếu và thiết bị Android thực tế.
