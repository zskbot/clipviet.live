CLIPVIET / ANDROID PLAYBACK MODULE

JiaoZi VideoPlayer

Tích hợp player Android native từ repository zskbot/jiaozivideoplayer (JZVideo/Jzvd, MIT). Thư viện hỗ trợ giao diện tùy biến, phát toàn màn hình, danh sách video và nhiều playback engine.

Phân biệt nền tảng: JiaoZiVideoPlayer là thư viện Android Java. Nó không chạy trực tiếp trong Safari/iPhone hoặc trình duyệt web. ClipViet Web tiếp tục dùng HTML5 video + HLS native của Safari / hls.js; trang này là hướng dẫn cho ứng dụng Android ClipViet.

1. Thêm thư viện Android

dependencies { implementation 'cn.jzvd:jiaozivideoplayer:7.7.0' }

2. Khai báo player trong layout

<cn.jzvd.JzvdStd android:id="@+id/clipviet_player" android:layout_width="match_parent" android:layout_height="220dp" />

3. Nạp nguồn video đã được cấp quyền

JzvdStd player = findViewById(R.id.clipviet_player);
// Chỉ truyền URL HTTPS được API ClipViet xác nhận quyền phát.
String authorizedVideoUrl = playbackResponse.getAuthorizedUrl();
player.setUp(authorizedVideoUrl, videoTitle);

4. Quản lý vòng đời Activity

@Override public void onBackPressed() { if (Jzvd.backPress()) return; super.onBackPressed(); }
@Override protected void onPause() { super.onPause(); Jzvd.releaseAllVideos(); }

5. Quy tắc tích hợp ClipViet

  • Chỉ bật phát khi API trả về quyền phát đã xác minh, còn hiệu lực và URL HTTPS hợp lệ.
  • Không dùng URL demo, video mẫu, URL scrape hoặc nguồn không có quyền phân phối.
  • Không ghi token/API key vào mã nguồn hoặc ứng dụng client.
  • Ứng dụng Android dùng JiaoZiVideoPlayer; website/iOS dùng player HTML5 riêng.
