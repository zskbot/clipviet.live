Catalog API Preview

Worker chỉ đọc cho Cloudflare Pages Preview. API lấy metadata từ các AppleCMS provider đã cấu hình; trình duyệt nhận JSON trực tiếp qua HTTPS/CORS.

Giới hạn triển khai: Đây là API Preview, không phải api.clipviet.live. Không có DNS/custom domain, không có endpoint ghi/xóa video, không có media proxy hoặc relay. Không sử dụng endpoint này cho Production.

Base URL

https://clipviet-catalog-api-preview.huynhthuongg2505-f9b.workers.dev

Endpoints

GET/health

Health status, môi trường và trạng thái cấu hình provider. Không trả secret.

GET/api/providers

Danh sách provider được cấu hình, cờ configured và tên hiển thị.

{ "data": [{ "id": "souavzy", "name": "Souavzy · Main", "configured": true }] }
GET/api/catalog/categories?sourceId=souavzy

Lấy danh mục. Bỏ sourceId để thử nguồn chính và failover khi upstream lỗi.

GET/api/catalog/videos?page=1&sourceId=souavzy

Danh sách video phân trang. Hỗ trợ keyword, categoryId, sourceId. Nếu bỏ source, Worker thử nguồn chính trước rồi mới failover.

{ "provider": { "id": "souavzy", "name": "Souavzy · Main" }, "items": [{ "id": "62843", "sourceId": "souavzy", "title": "..." }], "page": 1, "pageCount": 6537, "total": 130740, "limit": 20 }
GET/api/providers/{sourceId}/categories

Danh mục của một provider cụ thể.

GET/api/providers/{sourceId}/videos?page=1

Video list của provider cụ thể, hỗ trợ lọc danh mục và từ khóa.

GET/api/providers/{sourceId}/videos/{videoId}

Chi tiết video, bao gồm danh sách đường phát HTTPS nếu provider trả về.

CORS & playback

  • CORS chỉ cho phép các hostname Cloudflare Pages Preview được khai báo trong Worker.
  • Preflight hỗ trợ GET, OPTIONS, header Accept và Range.
  • Worker expose Accept-Ranges, Content-Range, Content-Length cho kiểm tra range.
  • MP4/HLS được phát trực tiếp từ media host của provider. Safari/iPhone dùng native HLS khi có hỗ trợ.
  • API không proxy, không relay segment, không tạo endpoint tải xuống.

Kiểm thử trên iPhone Safari

Mở trang chẩn đoán để kiểm tra JSON/CORS, MP4 MIME, HLS manifest/segment, HTTP Range 206 và HTMLVideoElement.loadeddata ngay trên thiết bị đang dùng.

MỞ SAFARI DIAGNOSTICS ↗

Các kết quả build upstream không thay thế kiểm thử HTTP thực tế trên Safari. Chỉ coi một endpoint hoặc media URL là đạt sau khi trang Diagnostics ghi nhận kết quả thành công.
